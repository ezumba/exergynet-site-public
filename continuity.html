Questions, answered

Built to fit how you work.

Is Agent Continuity another AI coding assistant?

No. It is a continuity and memory layer for supported AI coding clients. Claude Code, OpenCode, and Codex CLI remain the tools that perform the coding work.

Does my project get uploaded to ExergyNet?

Not in this local-first beta. The supported configuration stores local memory and checkpoints on your workstation. Feedback is optional and should never include credentials or confidential project content.

What happens when I restart my environment?

The local authority can reload persisted checkpoint state. The accepted three-client test included an authority restart before Codex CLI recovered and verified the prior checkpoint.

Can several people write to the same vault simultaneously?

Concurrent multi-writer operation is not qualified in this beta. Use sequential single-writer access to each local vault.

Is the beta open source?

The Vanguard Memory Node component is licensed separately under MIT, and third-party dependencies retain their own licenses. Newly authored ExergyNet CLI, bridge, and web components are intended for proprietary beta distribution, subject to final Trustee and legal approval.

Which operating systems are supported?

Linux and Ubuntu WSL2 were qualified, including Windows Claude Code through the WSL bridge. Native Windows without WSL2 and macOS remain experimental and have not received the same qualification.
