EDT-BENCH-001 Benchmark Report 2026-11-25 · LongMemEval-S · 500 Questions
ExergyNet Achieves 76.2% Accuracy on LongMemEval-S with 91.6% Lower Context Consumption
Across 500 standardized conversational memory questions, ExergyNet's xLMP Semantic Router delivered 381 correct answers — 35.1% more than session-level BM25 (282 correct) — while consuming 91.6% fewer provider-reported prompt tokens. The 1.8 pp observed advantage over the evidence-only Oracle was not statistically significant (McNemar p = 0.474). Evaluation used gemini-3.8-flash; a turn-level BM25 granularity control (B4) has not been conducted.

ExergyNet V5 Research Paper 2026-11-06 · Zenodo · DOI 10.5281/zenodo.24021817
Memory Grows. Context Does Not Have To.
ExergyNet V5 characterizes the relationship between persistent stored state and delivered active context at a development operating point. As stored memory scales toward and beyond 100 million tokens, delivered context per query remains bounded — by design. Reports retrieval performance from a live environment, accelerator infrastructure behavior, and a live authority-layer result from a production-adjacent environment.

Research Focus

What ExergyNet research investigates

Persistent Intelligence

How AI systems maintain relevant historical state across extended interactions without proportional growth in active context requirements.

Computational Efficiency

Measuring the relationship between memory scale, retrieval architecture, and prompt token consumption under standardized evaluation conditions.

Model-Independent Memory

Memory infrastructure that operates across model families without requiring model fine-tuning, context window expansion, or architectural modification.

Bounded Context Delivery

Architectures that deliver relevant evidence from large persistent stores within bounded context budgets, preserving accuracy while reducing computational overhead.
