03 Portal Registration & Bearer Auth

Create a developer account via POST https://portal.exergynet.org/auth/register (returns a one-time sk-exergy-... key) or in the Portal Key Manager.

cURL — Register & Verify Account
curl -X POST https://portal.exergynet.org/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"dev@example.com","password":"your-strong-password"}'

# Check balance & activation status:
curl https://portal.exergynet.org/developer/me \
  -H "Authorization: Bearer $EXERGYNET_API_KEY"

04 x402 V2 Base Mainnet Endpoints

GET https://x402.exergynet.org/v1/job?hash=<txHash> | ?jobId=<bytes32>
Pay-per-call ($0.02 Base Mainnet USDC via Coinbase CDP x402 V2). Returns HTTP 402 with a base64 Payment-Required header when called without payment; re-submit with an ERC-3009 Payment-Signature header to verify Base Mainnet transaction receipts, settlement status, 7-way USDC splits, and approved image ID.
cURL — Inspect 402 Payment Challenge
curl -i "https://x402.exergynet.org/v1/job?hash=0xc3cb476d77868437a4a01aed223c0604a71a437f37970fe7f0e7ea880399382c"
POST https://x402.exergynet.org/api/v1/compute/request
Unified Base Mainnet compute intake ($2.50 USDC: $2.00 V3 escrow + $0.50 spread). Requires a 190-byte LNE16BX2 payload encoded as payloadBase64, 64-hex vmnEvidenceRoot, Payment-Identifier (16–128 chars), and Payment-Signature. Note: when broadcast gates are locked (MAINNET_BROADCAST_ENABLED=false), requests without acceptPrepaidQueue:true fail closed with HTTP 503 so customer USDC is not captured unexpectedly.
JSON Request Body
{
  "payloadBase64": "<base64 190-byte LNE16BX2 payload>",
  "principalId": "0x...",
  "agentId": "my-agent-01",
  "tenantId": "tenant-id",
  "projectId": "proj-id",
  "vmnEvidenceRoot": "<64-char lowercase hex SHA-256>",
  "idempotencyKey": "unique-payment-id-0001"
}

07 Retired / Non-Operational Legacy Endpoints

// Do Not Build Against These Paths The following legacy paths were retired or quarantined and must not be used in new integrations:
  • https://explorer-api.exergynet.org/api/v1/estimate, /api/v1/compute/upload, /api/v1/jobs, /api/v1/jobs/{id}/proof → HTTP 404 (replaced by https://x402.exergynet.org/api/v1/compute/request & /v1/job).
  • https://explorer-api.exergynet.org/v1/chat/completions → HTTP 502 (moved to https://portal.exergynet.org/v1/chat/completions).
  • https://api.exergynet.org/v1 → DNS does not resolve (use https://portal.exergynet.org/v1).
  • https://portal.exergynet.org/api/vision/describe → HTTP 404 (removed).
  • https://portal.exergynet.org/api/billing/rho-sump → HTTP 503 (quarantined pending verified task pipeline).
