Governing Architecture

Type-II Physics: The Governing Computational Architecture

Type-II Physics provides the foundational architectural framework within which ExergyNet develops its proprietary computational systems — a physical computing architecture grounded in exergonic logic processing and deterministic state computation. ExergyNet's patent-pending technologies address specific functional expressions of this broader framework.

The Type-II Physics architecture is independently patent-pending, based on provisional patent applications filed in 2025. A nonprovisional patent application has been filed. The architectural relationship between Type-II Physics and ExergyNet's filed provisional applications represents a design relationship, not an established or expressly claimed patent priority chain. No legal priority relationship between these applications should be inferred from this presentation.

Domain 05

Physical state economics, post-inference energy attribution, telemetry-governed computational infrastructure, and execution-state mobility across compute nodes.
